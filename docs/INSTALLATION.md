# Installation

Extract `InstanceManager-1.1.5` and run `Instance Manager.exe` from a writable directory. Requires Windows 10/11 x64, .NET 8 Desktop Runtime x64, Microsoft Edge WebView2 Runtime and an installed Roblox client. Account data lives in `%APPDATA%\Instance Manager`, separate from the executable. Keep all downloaded files together and use the in-app updater for future releases.

Open Accounts > Add account, sign in on the actual Roblox page, choose a game and launch the selected accounts. See [Features](FEATURES.md), [Troubleshooting](TROUBLESHOOTING.md) and [Security](SECURITY.md).
